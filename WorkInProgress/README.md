# 🏦 Análise de Feedbacks Bancários com Inteligência Artificial

## 📋 Sobre o Projeto

Este projeto foi desenvolvido como solução para o desafio da **DIO (Digital Innovation One)**, cujo objetivo é aplicar conceitos de **Prompt Engineering** para criar instruções capazes de orientar uma Inteligência Artificial na análise de feedbacks de clientes bancários.

A proposta demonstra como um prompt bem estruturado pode transformar comentários de clientes em informações estratégicas para apoiar a tomada de decisão.

------

## 🎯 Objetivo

Criar um prompt capaz de:

- Analisar comentários de clientes bancários;
- Identificar reclamações recorrentes;
- Detectar elogios frequentes;
- Classificar sentimentos;
- Encontrar padrões e tendências;
- Gerar recomendações práticas;
- Apoiar equipes de Customer Experience (CX), Produtos e Atendimento.

------

## 🏦 Problema de Negócio

Instituições financeiras recebem diariamente milhares de comentários por diversos canais:

- Aplicativos móveis;
- Internet Banking;
- Atendimento telefônico;
- Chat online;
- Agências físicas;
- Redes sociais;
- Pesquisas de satisfação.

Analisar manualmente esse volume de informações é uma tarefa complexa e demorada.

A utilização de IA permite automatizar esse processo, desde que sejam fornecidas instruções claras, contexto adequado e restrições bem definidas.

------

## 🚀 Solução Desenvolvida

Foi criado um prompt estruturado que orienta a IA a:

1. Classificar feedbacks por sentimento.
2. Identificar temas recorrentes.
3. Detectar problemas críticos.
4. Identificar oportunidades de melhoria.
5. Gerar recomendações para as áreas responsáveis.
6. Respeitar regras de privacidade e proteção de dados.

## 🔒 Segurança e Privacidade

O prompt foi desenvolvido considerando boas práticas de governança de dados:

- Não expor CPF;
- Não expor números de conta;
- Não divulgar cartões;
- Não divulgar dados pessoais;
- Não criar informações inexistentes;
- Trabalhar apenas com dados fornecidos.

Este projeto demonstra como a qualidade das respostas geradas por uma Inteligência Artificial está diretamente relacionada à qualidade das instruções fornecidas.
