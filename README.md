# 🏦🤖 Análise de Feedbacks de Clientes Bancários com IA

## 📖 Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio da **DIO (Digital Innovation One)**, com o objetivo de aplicar técnicas de **Prompt Engineering** para orientar uma Inteligência Artificial na análise de feedbacks de clientes bancários.

A proposta consiste em construir um prompt capaz de transformar comentários e avaliações de clientes em **insights acionáveis**, apoiando equipes de experiência do cliente, atendimento e gestão na tomada de decisões.

---

## 🎯 Objetivo

Criar um prompt estruturado para que uma IA seja capaz de:

* Identificar reclamações recorrentes;
* Detectar elogios frequentes;
* Classificar sentimentos dos clientes;
* Encontrar padrões e tendências;
* Sugerir melhorias para produtos e serviços;
* Gerar relatórios executivos para apoio à decisão.

---

## 🧠 O Que a IA Deve Fazer

A IA atua como uma especialista em:

* Customer Experience (CX);
* Análise de Dados;
* Experiência Bancária;
* Análise de Sentimentos;
* Geração de Insights.

A partir dos feedbacks fornecidos, ela deve produzir análises claras, objetivas e baseadas exclusivamente nos dados recebidos.

## 🔒 Boas Práticas e Segurança

O prompt foi projetado seguindo princípios de privacidade e governança de dados:

✅ Não expor dados pessoais

✅ Não divulgar números de conta

✅ Não exibir CPF ou documentos

✅ Não inventar informações

✅ Informar limitações quando houver falta de dados
